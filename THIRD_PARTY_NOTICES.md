## Sound effects

Ten `.ogg` files in `assets/audio/sfx/`, all from the **Kenney Game Audio**
collection, released into the public domain under **CC0 1.0 Universal**. CC0
imposes no attribution requirement; the credit below is given voluntarily and as
a provenance record.

| | |
|---|---|
| Author | Kenney (Kenney Vleugels, kenney.nl) |
| Source | https://kenney.nl/assets/game-audio-starter-pack |
| Licence | CC0 1.0 Universal (public domain dedication) |
| Licence text | https://creativecommons.org/publicdomain/zero/1.0/ |

Files: `dissolved.ogg`, `enter_wet.ogg`, `level_fail.ogg`, `level_win.ogg`,
`obstacle_hit.ogg`, `pickup_shield.ogg`, `pickup_sliver.ogg`,
`shield_break.ogg`, `shrink_loop.ogg`, `star_ding.ogg`.

**Provenance evidence.** Five of the ten files still carry `ARTIST=Kenney` in
their embedded Vorbis comments, alongside
`COMMENTS=Sound generated by GameSynth from Tsugi (www.tsugi-studio.com)`, which
is the standard tagging on that pack. The remaining five carry no comment tags
but share the same encoder vendor string and encoding parameters, indicating the
same source pack with tags stripped. To reproduce this check:

```
python3 -c "
import glob,struct
for f in sorted(glob.glob('assets/audio/sfx/*.ogg')):
    d=open(f,'rb').read(); i=d.find(b'\x03vorbis')
    print(f, d[i:i+200] if i>=0 else 'no comment header')
"
```

If you ever need to prove this to Apple or anyone else, the CC0 dedication on
Kenney's packs is irrevocable and the source page above is the record.
